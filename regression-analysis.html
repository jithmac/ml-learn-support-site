Introduction to Regression Analysis

A visual roadmap and quick field guide to what is coming in the regression chapters: core concepts, key figures, equations, and diagnostic checklists at a glance.

What is Regression Analysis?

The Definition

Finding Relationships

A statistical method for discovering and describing connections between variables — mainly used to predict a continuous numerical value (like price, salary, or temperature).

The Goal

Building an Equation

Mathematically creates a formula between 1 Dependent Variable (Y) and Independent Variables (X) to predict unseen new values.

ŷ = b₀ + b₁x
ŷ: predicted value • b₀: intercept • b₁: slope
In Machine Learning

Supervised Learning

Categorized under supervised learning because the formula is derived from historical data + correct answers (labeled data). The algorithm learns by comparing its guesses against true results!

Roadmap: How Regression Works from Start to Finish

The step-by-step roadmap of building a regression model, from raw data points to making real-world predictions:

1
Collect data →

Have X (input) and Y (target) values.

2
Plot the data →

Usually visualised as a scatter plot.

3
Assume a line →

ŷ = b₀ + b₁x

4
Calculate errors →

Actual y − predicted ŷ.

5
Square the errors →

Prevent positive and negative errors from cancelling.

6
Find line with minimum SSE →

Choose b₀ and b₁ that give the smallest total squared error.

7
Get regression equation →

This is your mathematical best-fit line.

8
Use line for prediction →

Give a new X, and calculate its predicted Y.

Visual Topic Summaries: What to Expect

1. Regression Basics Core Concept

Predicts a continuous number along an unbroken spectrum.

House Size → Price Experience → Salary Time → Temperature
Key Distinction: Y = Dependent target (what we predict) • X = Independent predictor (input).
2. Simple Linear Regression ⭐ ⭐ Essential
ŷ = b₀ + b₁x
• ŷ = Predicted output
• b₀ = Intercept (baseline when x = 0)
• b₁ = Slope (rate of change in Y per unit change in X)
Goal: Find the line giving the smallest total error across all points.
3. Least Squares Method (OLS) ⭐ ⭐ Essential
Residual (e) = Actual (y) − Predicted (ŷ)
Why square errors? Stops positive and negative errors canceling each other, heavily punishes big blunders, and enables exact calculus solutions!
4. SSE, SSR and SST ⭐ ⭐ Essential
SST = SSR + SSE
• SST = Total variation in actual Y around mean (ȳ)
• SSR = Variation explained by regression model
• SSE = Unexplained residual error
SSR (Explained: 75%)
SSE (25%)
Mental Model: Total Variation = Explained + Unexplained.
5. R² — Determination ⭐ ⭐ Essential
R² = SSR / SST = 1 − (SSE / SST)
Tells us how much of the variation in Y is explained by the model.
Example: R² = 0.80 → 80% explained!
Caution: A high R² alone does not prove a good model! Use Adjusted R² to prevent junk features inflating the score.
6. Regression Error Metrics Evaluation
• MAE: Average error. “On average, how far off am I?”
• MSE: Average squared error; heavily penalizes big misses.
• RMSE: Square root of MSE; expressed in the same units as Y ($).
Cheat Sheet: MAE for stakeholder clarity • RMSE for heavy penalties on large blunders.
7. Multiple Linear Regression ⭐ ⭐ Essential
ŷ = b₀ + b₁x₁ + b₂x₂ + b₃x₃ + …

Predicts house price using size, bedrooms, location, and age simultaneously.

Ceteris Paribus: Each coefficient shows how Y changes for that variable while keeping all other variables constant.
8. Regression Assumptions ⭐ ⭐ Essential
1. Linearity
4. Normal errors
2. Independence
5. No multicollinearity
3. Homoscedasticity
6. Mean error = 0
Diagnostic: Check Residual Plots. Errors must form an even, random cloud with no funnel shape or curves!
9. Multicollinearity Feature Trouble

Happens when predictors are strongly related (e.g., size in m² vs. size in ft²).

VIF (Variance Inflation Factor) > 5 or 10 = Danger!
Problem: Makes it hard to determine individual effects. Fix: Drop redundant feature or apply Ridge.
10. Statistical Inference Significance
• t-test: Tests an individual coefficient (Is it ≠ 0?)
• F-test: Tests the overall regression model
• p-value: Evidence against null hypothesis (p < 0.05)
• Confidence Interval: Plausible parameter range
11. ANOVA in Regression Variance Table

Partitions total variation into Explained vs. Error in a structured table:

SS • df • Mean Square • F-statistic • p-value
12. Polynomial Regression Bending Lines
y = b₀ + b₁x + b₂x²

Captures curved relationships. Still treated as linear regression because it is linear in its coefficients!

13. Ridge Regression L2 Regularization
Loss = SSE + λ ∑ bⱼ²

Adds an L2 penalty. Shrinks large coefficients smoothly toward zero to control overfitting and handle collinear features.

14. Lasso Regression L1 Regularization
Loss = SSE + λ ∑ |bⱼ|

Adds an L1 penalty. Can shrink unneeded coefficients to exactly zero — performing built-in feature selection!

15. Overfitting & Underfitting Bias vs Variance
• Underfitting: Model too simple (poor train + test).
• Overfitting: Learns noise (good train + poor test).
Remedy: Regularization (Ridge/Lasso) reduces overfitting.
16. Train/Test Split Generalization
80% Training Data
20% Test

Never test on training data. Evaluates whether the model generalizes to unseen examples.

17. Cross-Validation K-Fold

Divides training data into K folds, rotating the validation fold.

Prevents lucky/unlucky splits → gives a reliable estimate of model performance!
18. Logistic Regression Classification
p = 1 / (1 + e−‌ᶻ)

Used for classification (Spam / Not spam), not continuous values! Uses the sigmoid function to output probabilities between 0 and 1.

🧠 The Big Picture: Diagnostic Playbook

Input Variables (X)  →  Regression Model  →  Prediction (ŷ)

When building any regression model, keep this question-and-answer checklist in mind:

Q1
How good is the prediction?

→ Check MAE, MSE, RMSE, R²

Q2
How much variation does the model explain?

→ Check SSR, SST, R²

Q3
How much error remains?

→ Check SSE

Q4
Is the model statistically valid?

→ Check 6 Assumptions, t-test, F-test, p-values

Q5
Are the features causing problems?

→ Check Multicollinearity, VIF (> 5 or 10)

Q6
Is the model overfitting?

→ Check Train/Test split, K-Fold Cross-Validation

Q7
Is the model too complex?

→ Apply Ridge (L2) or Lasso (L1) Regularization

Q8
Is the relationship curved?

→ Upgrade to Polynomial Regression (x², x³)
