Simple Linear Regression

The easiest and most common way to start learning regression. Learn how a single straight line connects two continuous variables — what the slope, intercept, and error mean, and why finding the line is so important.

The Most Simple Method of Regression

In the previous chapter (4.6 Introduction to Regression), we saw an overview of regression models. Now we start with the simplest one of all: Simple Linear Regression.

Why "Simple"?

Only 1 Input & 1 Output

It is called "simple" because we use only one input variable (x) to predict one output variable (y). No complicated formulas with many features!

Why "Linear"?

A Straight Line

"Linear" means a straight line. We assume the relationship between our two variables can be drawn as a straight line on a graph.

Why "Regression"?

Continuous Numbers

Regression means we are predicting a continuous number (like price, score, or temperature), not categories like "yes" or "no".

📌 What is a "Continuous Variable"?

A continuous variable is any number that can have decimals or fractions. For example: study time (like 2.5 hours), height (like 1.75 meters), or price (like $120.50). Simple Linear Regression is a statistical method for studying the relationship between two continuous variables.

The Two Variables: x (Input) and y (Output)

Simple linear regression connects two variables: one independent variable (x) and one dependent variable (y). Here is what they mean in simple words:

Horizontal Axis x

x = Independent Variable

This is the input. It stands on its own. You already know or control this number (for example, how many hours you study).

Simple rule: Think of x as the cause or the question.
Vertical Axis y

y = Dependent Variable

This is the output. It is called "dependent" because its value depends on x (for example, your exam score depends on how much you study).

Simple rule: Think of y as the effect or the answer you want to predict.
💡 Click each example to see the relationship:
Input (x): Hours of Study (hours)  •  Output to predict (y): Exam Score (points)
The more hours you study (x), the higher your exam score (y) will be.

The Main Difference: Simple vs. Multiple Linear Regression

The primary distinction between the two models is how many independent (X) variables are used to predict one dependent (Y) variable.
1 Input (X) 1 X → 1 Y

1. Simple Linear Regression

Uses ONE independent variable (X) to predict ONE dependent variable (Y).

General Equation
Y = β₀ + β₁X + ε
Example: Predict a student's exam score based on study hours:
Score = β₀ + β₁(StudyHours)
💡 Core Rule: Exactly 1 X → 1 Y (Forms a straight line in 2D space)
2 or More Inputs (X's) Multiple X's → 1 Y

2. Multiple Linear Regression

Uses TWO or MORE independent variables (X's) to predict ONE dependent variable (Y).

General Equation
Y = β₀ + β₁X₁ + β₂X₂ + β₃X₃ + … + ε
Example: Predict exam score using study hours (X₁), attendance (X₂), and assignment marks (X₃):
Score = β₀ + β₁StudyHours + β₂Attendance + β₃AssignmentMarks
💡 Core Rule: Multiple X's → 1 Y (Forms a 3D plane or multidimensional hyperplane)
📊 Side-by-Side Comparison: The Key Difference
Feature Simple Linear Regression Multiple Linear Regression
Number of X variables 1 2 or more
Number of Y variables 1 1
Equation Y = β₀ + β₁X Y = β₀ + β₁X₁ + β₂X₂ + …
Example Score ← Study hours Score ← Study hours + Attendance + Assignments
Geometric Shape A straight line (2D) A plane (3D) or hyperplane (>3D)
🎛️

One Important Thing: The Sound Mixing Board Analogy

In multiple regression, each coefficient tells you the effect of that variable while keeping the other X variables constant (statisticians call this principle “ceteris paribus”).

Example Multiple Regression Model:
Score = 20 + 5(StudyHours) + 0.3(Attendance)

The coefficient 5 means:
“For each additional study hour, predicted score increases by 5 points, assuming attendance stays the same.”

📻 Simple Regression = Single Volume Knob

There is only one dial on the device. When you turn study hours up, the score rises directly. You don't have to freeze or balance anything else because no other dials exist!

🎚️ Multiple Regression = Audio Mixing Board

You have a whole row of sliders (Study Hours, Attendance, Assignments). To measure the true power of Study Hours, you push that single slider up while your other fingers hold Attendance and Assignments completely still.

📌 That “keeping other variables constant” idea is one of the most important concepts to understand when moving from Simple to Multiple regression!

This equation connects the input variable (x) to the output variable (y) using standard Greek symbols: β₀ (intercept), β₁ (slope), and ε₁ (error).

This equation creates a relationship between the two variables. It connects the input x to the output y:

💡 How to Read the Slope Coefficient (β₁): The “Single Knob” Rule

Slope Interpretation

Suppose our simple linear regression model predicts a student's exam score based on study hours:

Score = 30 + 5(StudyHours)

The slope coefficient 5 simply means:

“For every 1 extra hour you study, your predicted exam score jumps by 5 points.”
🎛️ The “Single Knob” Concept: Think of Simple Linear Regression like an old radio with only one volume knob. You never have to worry about “holding other variables constant” because no other dials exist! It gives you a pure, direct 1-on-1 spotlight connecting x directly to y.

Finding the Values of β₀ and β₁ is the Main Process

Finding the exact values for the slope (β₁) and intercept (β₀) is the whole goal of simple linear regression.

Finding the values of β₀ and β₁ is the main process of simple linear regression.

Why? Think about a graph with data dots scattered on it. You could draw hundreds of different straight lines through those dots. Some lines would be too high, some too low, and some completely in the wrong direction.

The Problem

Too Many Possible Lines

If you pick random numbers for β₀ and β₁, your line will miss most of the dots and make terrible predictions.

Line 1: Too steep (bad guesses)
Line 2: Goes the wrong way!
The Goal

Find the One "Best-Fit" Line

We want to find the one line that stays as close to all the dots as possible. This means making the total error as small as possible!

Best Line: Has the smallest total error!
The Mathematics of Ordinary Least Squares

How We Calculate β₁ (Slope) and β₀ (Intercept)

OLS Closed-Form Formulas

To find the single best-fitting straight line among infinite possibilities, statistics uses a method called Ordinary Least Squares (OLS). Rather than trial-and-error, OLS provides exact mathematical equations to compute the slope (β₁) and intercept (β₀) directly from your dataset.

The direct formula is widely used by computers and calculators because you can compute all the sums in a single pass over your data without calculating the averages first!

The Underlying Criterion: Minimizing the Sum of Squared Errors (SSE) Objective Function

Why do the formulas in Step 1 and Step 2 look the way they do? They are the mathematical result of minimizing the Sum of Squared Errors (SSE) — the total squared vertical distance from each real dot to the line:

Minimize SSE = ∑ εi² = ∑ (yi − ŷi)² = ∑ [yi − (β₀ + β₁xi)]²

Using calculus (setting the partial derivatives ∂SSE/∂β₀ = 0 and ∂SSE/∂β₁ = 0), we find the single minimum point. This guarantees that no other straight line in the universe has a smaller sum of squared errors for this data!

🎯 The Final Prediction Equation (The Fitted Line) Fitted Regression Model

Once the computer calculates the numerical values for β₀ and β₁, your machine learning model is ready to predict. For any new input value x, plug it in to calculate ŷ (pronounced "y-hat"):

ŷ = β₀ + β₁x
📌 Notice: The error term (± ε₁) is absent here. That is because ŷ is our clean, predicted average on the line. The error only exists when comparing real-world observations (y) against the line's prediction (ŷ).

The ANOVA Table: Is the Model Statistically Significant?

Once we find β₀ and β₁ and draw our regression line, we must answer a very important question: Is this relationship real, or did it happen just by lucky chance?

💡 What Does “Statistically Significant” Mean?

It means: based on our observed data, we have enough statistical evidence to prove that a real linear relationship exists between the variables. We can trust that x genuinely helps predict y, and the pattern is not just random coincidence in our sample points.

Step 1: Set Up the Hypotheses

Before checking the numbers, we set up two competing statements:

Null Hypothesis (H₀) H₀ : β₁ = 0

No significant relationship. The slope is zero (a flat line). Changing x tells us nothing about y. Any slope seen in our sample dots is just random luck.

Alternative Hypothesis (H₁) H₁ : β₁ ≠ 0

A real relationship exists! The slope is not zero. As x changes, y really changes with it. The regression line has true predictive value.

Step 2: Split the Variation — SSR, SSE, and SST

ANOVA stands for Analysis of Variance. It tests significance by splitting the total variation in our data into two parts: variation explained by the line, and unexplained error.

The Golden Rule of Variation
SST = SSR + SSE
Total Variation = Variation Explained by the Line + Unexplained Error (Noise)
SST Total Variation
SST = ∑(yᵢ − ȳ)²

Total Sum of Squares: Measures the total spread of all real data points (yᵢ) around the overall average (ȳ).

SSR Explained by Line
SSR = ∑(ŷᵢ − ȳ)²

Regression Sum of Squares: Measures how much variation our fitted line (ŷᵢ) successfully explains compared to the simple average (ȳ).

SSE Unexplained Error
SSE = ∑(yᵢ − ŷᵢ)²

Error Sum of Squares: Measures the leftover noise — the distance between real points (yᵢ) and what the line predicted (ŷᵢ).

💡 What are “Degrees of Freedom” (df)?

Degrees of freedom = how many values can vary independently before the remaining values become determined.

• Regression (df = 1): We have exactly 1 independent predictor variable (x) free to vary.
• Error (df = n − 2): Out of n data points, 2 values become determined by calculating the intercept (β₀) and slope (β₁). The remaining (n − 2) values are free to vary independently.
• Total (df = n − 1): 1 value becomes determined by fixing the overall mean (ȳ). The remaining (n − 1) values can vary freely.

💡 Intuitive meaning: Think of the F-statistic as a Signal-to-Noise Ratio. The numerator (MSR) is the signal captured by your line; the denominator (MSE) is background noise. When the signal is much stronger than the noise (large F), we reject H₀ and conclude that x truly helps predict y!

Step 4: Making the Decision with the F-Value and p-Value

The F-value compares the signal (variation explained by the line, MSR) to the noise (random error, MSE). Using the calculated F-value and the degrees of freedom (1 and n − 2), we look up the p-value from an F-distribution table (or statistical software). Then we compare p with our significance threshold (usually 0.05):

✅ If p < 0.05 — Reject the NULL Hypothesis

Because p is smaller than 0.05, we reject H₀.

What it means: The slope is NOT zero (β₁ ≠ 0). There is a statistically significant linear relationship between the variables!
❌ If p ≥ 0.05 — Fail to Reject H₀

Because p is 0.05 or greater, we fail to reject H₀.

What it means: There is not enough evidence to prove a linear relationship exists. Any slope could simply be random noise.
🎯 Quick Example: Study Hours vs. Exam Score

Suppose we measure n = 22 students and calculate SSR = 480 and SSE = 120 (so SST = 600):
• MSR = 480 / 1 = 480
• MSE = 120 / (22 − 2) = 120 / 20 = 6.0
• F = MSR / MSE = 480 / 6.0 = 80.0
Using the F-table with df₁ = 1 and df₂ = 20, an F of 80.0 gives p < 0.0001.
Since p < 0.05, we reject the NULL hypothesis — proving there is a statistically significant linear relationship between study hours and exam score!

Summary: 4 Things to Remember

1. Simple vs. Multiple

Simple Regression uses 1 input (x) → 1 output (y) (a single knob). Multiple Regression uses 2 or more inputs (x₁, x₂, ...) while keeping other variables constant.

2. The Line Equation

y = β₀ ± β₁x ± ε₁ where β₀ is the intercept, β₁ is the slope, and ε₁ is the error.

3. The Main Goal

Finding β₀ and β₁ is the main process. Once found, we have the best line with minimum squared error.

4. Statistical Significance

We test H₀ : β₁ = 0 using the ANOVA table (F = MSR / MSE). If p < 0.05, we reject H₀ and prove the relationship is real!
