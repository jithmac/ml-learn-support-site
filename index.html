Introduction to Machine Learning

Before you train a single model, it helps to know what the field is actually claiming to do, and why it looks so different from the programming you already know.

What is artificial intelligence?

Machine learning doesn't stand on its own. It's one way of building artificial intelligence, so it's worth pinning down what that term is actually asking for.

Artificial intelligence is the simulation of human intelligence inside a machine: a system built or programmed to mimic the way people sense, decide, and act.

That's a broad goal, and it can be reached in more than one way. A chess program that searches through millions of possible moves is artificial intelligence. So is a thermostat-like system that follows a long list of hand-written rules. Machine learning is simply the branch of AI that reaches this goal through data, rather than through rules a person writes out by hand.

What is machine learning?

In plain terms: machine learning is the part of AI where a computer learns patterns from examples instead of being told the rules directly, and then uses those patterns to make predictions or decisions about new situations it hasn't seen before.

Formal definition

Machine learning is a subset of artificial intelligence in which a system improves its performance on a task by learning statistical patterns from data, rather than by following explicitly hand-coded instructions for that task.

The two definitions describe the same thing at different altitudes. The plain one is enough to get started; the formal one is the phrasing you'll meet again in papers and textbooks.

Two ways to arrive at a program

The cleanest way to feel the difference is to look at what goes in and what comes out. In both cases you start with data, but which piece is missing is what defines the approach.

Why machine learning keeps getting better

Machine learning itself is an old idea. Some of its core algorithms date back decades. What changed is the environment around it. Three conditions arrived together, and each one removes a limit the field used to run into.

Data, at a scale no one had before

Every device, sensor, and click leaves a record. Patterns that need thousands or millions of examples to surface finally have enough examples to learn from, in volume and in variety.

Computation, now affordable

The processing power once locked inside research labs (especially GPUs built for parallel work) is now something a student can rent by the hour.

Connectivity, fast enough to matter

High-speed internet moves the enormous datasets above from where they're collected to where they're trained, and puts trained models within reach of anyone with a connection.

The three branches of machine learning

Almost everything in the field falls under one of three approaches, split by a single question: what kind of feedback does the computer learn from? Select each branch to see what it means and which algorithms live there.

Machine Learning
Supervised Learning learns from labelled answers

Studies examples that already have the correct answer attached, then learns to predict answers for new, unlabelled examples.

Linear Regression Decision Trees SVMs
Unsupervised Learning finds structure with no answers

Receives data with no correct answers attached, and has to find hidden structure or groupings on its own.

K-Means PCA Autoencoders
Reinforcement Learning learns from reward

An agent takes actions inside an environment, receives a reward or penalty, and gradually learns which actions pay off.
