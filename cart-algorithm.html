Decision Trees: CART Algorithm

The modern industry standard: Strictly binary trees, Gini Impurity, regression trees for predicting continuous numbers, and cost-complexity pruning.

The CART Algorithm: Classification & Regression Trees

The Modern Workhorse

CART stands for Classification And Regression Trees. Created in 1984 by Leo Breiman and his team, it is the industry standard decision tree algorithm today — and it is the exact engine behind Python's scikit-learn!

While ID3 and C4.5 were brilliant stepping stones, they had quirks: ID3 got tricked by IDs, and both built messy multi-way branches. CART made trees practical and fast by following two simple, powerful ideas:

✌️ 1. The Game of 20 Questions

Strictly Binary (Always 2 Branches)

Instead of splitting into 3, 4, or 5 messy branches at once (like Sunny, Overcast, Rain), CART plays the game of 20 Questions: every single test is strictly a Yes or No question!

Example: “Is Outlook == Sunny?” → [Yes] or [No]

🎯 2. Double Duty: Two Jobs in One

Predicts Categories AND Numbers

ID3 and C4.5 can only do classification (picking discrete labels like Yes/No). CART can also do regression — predicting real numbers like house prices, salaries, or playing minutes!

Output: Category (Yes/No) OR Number ($65,000)

What is Gini Impurity? (In Plain English)

For classification, CART doesn't use Entropy or logarithms. Instead, it measures how mixed up a group is using something much simpler: Gini Impurity.

Intuition: The "Lucky Dip" Bag

Imagine reaching into a bag of colored balls without looking, pulling one out, and trying to guess its color:

🟢 10 Green • 🔴 0 Red

Every ball is green. You'll guess "Green" and be right 100% of the time. Zero confusion!

➡️ Gini = 0.0 (100% Pure!)
🟢 5 Green • 🔴 5 Red

Half green, half red. It's a complete coin flip. You'll guess wrong half the time!

➡️ Gini = 0.50 (Maximum Disorder)

Here is the simple math behind Gini Impurity for any group:

Gini = 1 − Σ (pi)2
For two classes (Yes and No):   Gini = 1 − [ p(Yes)² + p(No)² ]
⚡ Why Data Scientists Love Gini: Entropy requires computing logarithms (log₂), which is slow on millions of rows. Gini only requires simple multiplications (squaring) and subtractions. It runs much faster on computers and makes almost identical decisions!
🎾 CART in Action

Step-by-Step Example: Building the Tree with CART

Let's use our familiar 10-day Tennis dataset from the ID3 lesson. Watch how CART evaluates simple Yes/No questions and builds a clean binary decision tree.

A

Step A: Calculate Overall Starting Gini (The Baseline)

Across all 10 days in our dataset, we have 6 "Yes" and 4 "No":

• Total Days: S = 10 | p(Yes) = 6/10 = 0.60 | p(No) = 4/10 = 0.40
Gini(S) = 1 − [ (0.60)² + (0.40)² ]
Gini(S) = 1 − [ 0.36 + 0.16 ] = 1 − 0.52 = 0.4800
0.0 (Pure / Certain) Starting Impurity: 0.4800 / 0.5000 0.50 (Max Confusion)

💡 Our starting score is 0.4800. Any good Yes/No question must drop this impurity score closer to 0!

B

Step B: Test Candidate Yes/No Questions

Because CART is strictly binary, it turns each feature into a simple Yes or No question. Let's see what happens when we ask: "Is Outlook == Sunny?"

Testing Question: “Is Outlook == Sunny?” Drop in Impurity = +0.1633
👉 If YES (4 Days: D1, D2, D8, D9)
Contains: 1 Yes, 3 No
Gini(Left) = 1 − [ (1/4)² + (3/4)² ]
= 1 − [ 0.0625 + 0.5625 ] = 0.3750
👉 If NO (6 Days: D3, D4, D5, D6, D7, D10)
Contains: 5 Yes, 1 No
Gini(Right) = 1 − [ (5/6)² + (1/6)² ]
= 1 − [ 0.6944 + 0.0278 ] = 0.2778
Weighted Gini after split: (4/10)×0.3750 + (6/10)×0.2778 = 0.3167
Gini Gain (Drop in Disorder): 0.4800 − 0.3167 = 0.1633
Testing Other Candidate Yes/No Questions — Calculated Likewise:
☁️ Is Outlook == Overcast? Rank #2

Splits into: Overcast (2 Yes, 0 No → Pure!) vs. Others (4 Yes, 4 No).

Weighted Gini = 0.4000 • Gain = 0.0800
💧 Is Humidity == Normal? Rank #3

Splits into: Normal (4 Yes, 1 No) vs. High (2 Yes, 3 No).

Weighted Gini = 0.4000 • Gain = 0.0800
💨 Is Wind == Weak? Rank #4

Splits into: Weak (5 Yes, 2 No) vs. Strong (1 Yes, 2 No).

Weighted Gini = 0.4190 • Gain = 0.0610
🏆 The Winner: "Is Outlook == Sunny?" produces the highest Gini Gain (0.1633) and drops disorder the most. CART crowns it as the Root Node at the top of the tree!
C

Step C: Repeat on Each Branch Until Every Leaf is 100% Pure

Just like ID3 and C4.5, CART repeats this process recursively on each branch:

  • On the YES side (Outlook is Sunny • 4 days):
    CART tests: "Is Humidity == High?"
    • Yes (3 days: D1, D2, D8): All 3 are "No" → 🎯 Leaf: Play = NO (100% Pure!)
    • No (1 day: D9): It is "Yes" → 🎯 Leaf: Play = YES (100% Pure!)
  • On the NO side (Outlook is Not Sunny • 6 days):
    CART tests: "Is Wind == Weak?"
    • Yes (4 days: D3, D4, D5, D10): All 4 are "Yes" → 🎯 Leaf: Play = YES (100% Pure!)
    • No (2 days: D6, D7): 1 Yes, 1 No. CART asks "Is Outlook == Overcast?":
      – Yes (D7): 🎯 Leaf: Play = YES
      – No (D6 - Rain): 🎯 Leaf: Play = NO
🎯 Trained CART Binary Decision Tree
Notice: Every Single Node Has Exactly 2 Branches (Yes / No)!
Learned CART Decision Rules:
1. IF (Outlook == Sunny) AND (Humidity == High) → Play = NO
2. IF (Outlook == Sunny) AND (Humidity == Normal) → Play = YES
3. IF (Outlook != Sunny) AND (Wind == Weak) → Play = YES
4. IF (Outlook == Rain) AND (Wind == Strong) → Play = NO
5. IF (Outlook == Overcast) AND (Wind == Strong) → Play = YES

The “R” in CART: Predicting Real Numbers (Regression Trees)

What if your goal is not a "Yes" or "No" label, but a real continuous number? For example: “How many minutes will someone play tennis today?” (30 min? 75 min? 120 min?) or “What is the price of this house?”

1. How It Splits: Minimizing Spread

Instead of checking for class purity with Gini, CART checks the average value of each group. It picks the split that groups similar numbers together, minimizing the Mean Squared Error (MSE).

2. What the Leaf Predicts: The Group Average

When a new instance lands on a leaf node, its predicted number is simply the Average (Mean) of all training samples in that leaf!

Example: Predicting Tennis Playing Time (Minutes)
CONDITION
Temperature ≤ 18°C (Cold)
Times: [30m, 40m, 35m]
Predicted: 35 Minutes
↔
CONDITION
Temperature > 18°C (Warm)
Times: [90m, 110m, 100m]
Predicted: 100 Minutes

How CART Stops Overfitting: The "Simplicity Rule"

Just like ID3, if you let CART run forever without stopping, it will grow tiny branches to isolate every single weird row in your training set.

Cost-Complexity Pruning (The "Tree Tax")

Think of writing an essay: A 100-page essay mentions every single trivial fact, but nobody can read it. A clean 3-page summary captures the big picture.

CART uses a clever mathematical method called Cost-Complexity Pruning:

  • CART first grows a full, deep tree.
  • Then, it attaches a "simplicity penalty" (α) to every single branch. Every extra branch has to "pay rent".
  • If a branch does not improve prediction accuracy enough to justify its cost, CART snips it off!
Total Cost = Training Errors + ( α × Number of Leaves )

The Grand Summary: ID3 vs. C4.5 vs. CART

A simple side-by-side comparison of all three landmark algorithms:

Feature ID3 (1986) C4.5 (1993) CART (Modern Standard)
Author Ross Quinlan Ross Quinlan Breiman, Friedman, Olshen, Stone
Splitting Metric Information Gain (Entropy) Gain Ratio (Entropy ÷ SplitInfo) Gini Impurity (or MSE for numbers)
Split Style Multi-way (many branches) Multi-way & numeric cutoffs Strictly Binary (Always 2 branches)
Supported Tasks Classification only Classification only Classification & Regression!
Handles Continuous Numbers? ❌ No (categories only) ✔️ Yes (finds cutoffs) ✔️ Yes (binary midpoint cutoffs)
Pruning (Stops Overfitting) ❌ None ✔️ Pessimistic Error Pruning ✔️ Cost-Complexity Pruning
Where It Is Used Today Historical foundation Academic reference (Weka J48) Python Scikit-Learn • Base for Random Forests & XGBoost!
🎉 The Big Takeaway: ID3 gave us the idea of growing trees with entropy. C4.5 fixed the multi-valued attribute trap and introduced numbers. But CART gave us clean, blazing-fast, strictly binary trees that can predict both categories and numbers — making it the foundational building block for modern ensemble algorithms like Random Forests and Gradient Boosting (XGBoost)!
