Decision Trees: ID3 Algorithm

The pioneer decision tree algorithm: Measuring uncertainty with Shannon Entropy and choosing the best splitting attributes with Information Gain.

ID3 Algorithm

The ID3 algorithm uses Information Gain as the attribute selection measure. To calculate Information Gain, first the Entropy of each and every attribute must be calculated.

What is Entropy?

Entropy measures how mixed or uncertain the outcome of the data is. It is a mathematical measure of impurity/uncertainty.

Example: The Box of Balls

Imagine a box containing balls:

🟢 10 green balls
🔴 0 red balls

There is no uncertainty. If I pick one, I know it will be green.

➡️ Entropy = 0
🟢 5 green balls
🔴 5 red balls

I don't know which one I'll pick.

➡️ High uncertainty → high entropy

The below equation is used to measure the entropy:

Entropy ( S ) = − ∑ i = 1 c p i log 2 ( p i )
How does this entropy come to known?
Core Concept

Information Theory is a branch of computer science that provides a way to measure how uncertain something is. It fundamentally bridges Computer Science, Mathematics, and Data Science.

Information in the world takes many forms. For many purposes, this information needs to be measured:

📝 Letters 🔢 Numbers 🖼️ Images 🎵 Audio 🎥 Video 🧩 Patterns

But since there are so many forms of information, how do we find a fundamental unit of measure for it all?

The Bit

The fundamental unit of measuring information is the Bit (Binary Digit). It gives us a universal currency to quantify data.

Entropy

While bits measure capacity, Entropy measures the amount of uncertainty or surprise contained within that information.

Together, Bits and Entropy give us a complete system to measure information properly!
ID3 Algorithm in Action

Dataset & Calculating the Entropy of Each Variable

Before ID3 can pick the best attribute to split the data, it must measure the impurity (uncertainty) of the whole dataset, and then determine how much entropy remains when splitting on each individual attribute.

Step A: Total Baseline Entropy of Dataset S — E(S)

E(S) = 0.9710

Before analyzing attributes, we calculate the overall uncertainty of the target variable Play Tennis across all 10 instances (6 “Yes”, 4 “No”):

Why? Because we need a baseline to know how much entropy we can remove by taking one branch.
• Total Instances: S = 10 | p(Yes) = 6/10 = 0.60 | p(No) = 4/10 = 0.40
Entropy(S) = − [ p(Yes)·log2(p(Yes)) + p(No)·log2(p(No)) ]
Entropy(S) = − [ 0.60·log2(0.60) + 0.40·log2(0.40) ]
Entropy(S) = − [ 0.60×(−0.7370) + 0.40×(−1.3219) ] = 0.4422 + 0.5288 = 0.9710 bits
0.0 (Pure / Certain) Dataset Impurity: 0.9710 / 1.0000 bits 1.0 (Maximum Disorder)

Step B: Calculating Entropy for Each Variable

Reference Feature • Fully Explained

Entropy of Variable: Outlook

Weighted Entropy E(S, Outlook) = 0.6490

The variable Outlook splits our 10 rows into 3 distinct subsets: Sunny (4 rows), Overcast (2 rows), and Rain (4 rows). First, we calculate the entropy for each branch separately:

Sunny 4 / 10 rows
Instances: D1, D2, D8, D9 → 1 Yes, 3 No
E(Sunny) = − [ 1/4 log2(1/4) + 3/4 log2(3/4) ]
= − [ 0.25×(−2) + 0.75×(−0.415) ]
= 0.8113 bits
Overcast Zero Impurity!
Instances: D3, D7 → 2 Yes, 0 No (100% Pure!)
E(Overcast) = − [ 2/2 log2(2/2) + 0 ]
= − [ 1 × 0 ]
= 0.0000 bits (Pure)
Rain 4 / 10 rows
Instances: D4, D5, D6, D10 → 3 Yes, 1 No
E(Rain) = − [ 3/4 log2(3/4) + 1/4 log2(1/4) ]
= − [ 0.75×(−0.415) + 0.25×(−2) ]
= 0.8113 bits
Why use weighted entropy? Because each branch has a different number of data entries. If we directly reduce the branch entropy from the overall entropy, that would give misleading information. So we use weighted entropy, which allows us to give each branch importance according to the number of samples it contains.
Weighted Average Entropy: E(S, Outlook)
We multiply each branch's entropy by its proportional share of total instances:
E(S, Outlook) = (|SSunny|/|S|)·E(Sunny) + (|SOvercast|/|S|)·E(Overcast) + (|SRain|/|S|)·E(Rain)
E(S, Outlook) = (4/10)×0.8113 + (2/10)×0.0000 + (4/10)×0.8113
E(S, Outlook) = 0.3245 + 0 + 0.3245 = 0.6490 bits

Step C: Information Gain & Choosing the Root Node

Step C: Information Gain

Metric: IG(S, A) = E(S) − E(S, A)

Information Gain is the amount of uncertainty reduced after splitting the data using an attribute. It tells us how much cleaner and more organized our predictions become once we divide our data along a specific feature.

Entropy Before Split
E(S) = 0.9710
Overall uncertainty across all 10 rows (from Step A)
−
Weighted Entropy After Split
E(S, Attribute)
Remaining disorder after dividing into branches (from Step B)
=
Information Gain (IG)
IG(S, Attribute)
Net uncertainty removed — the higher, the better!
💡
How to Remember & Understand Information Gain
This is basically the entropy difference before and after the split:
  • Overall entropy is the entropy before the split.
  • Weighted entropy is the entropy after the split.
  • By finding the difference, we get the exact amount of entropy reduced by each split. More entropy reduction means it is easier to predict a value!
⚡ Higher Information Gain → Greater reduction in uncertainty → Better attribute for the split!

Step D: Recursive Splitting & Mathematical Resolution

Stopping Condition: Entropy = 0.0000 on Every Branch

ID3 is a recursive algorithm. After choosing Outlook as the root node, our dataset was divided into 3 branches. For any branch that is still mixed, we repeat the exact same math: calculate the subset's baseline entropy, compute the weighted entropy and Information Gain for the remaining features, and split on the highest-gain feature until every branch reaches a pure Leaf Node.
